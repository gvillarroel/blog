# Recetario Zojirushi BB-PDC20 / BB-PPC20

Paquete de trabajo generado a partir del recetario público de Zojirushi.

## Archivos principales

- [Guía para transformar cualquier receta a esta panificadora](guia-transformacion-recetas-panificadora.es.md)
- [Plantilla reutilizable para documentar y calibrar una conversión](plantilla-conversion-receta.es.md)
- [Evidencia: comparación receta de referencia frente a adaptación para máquina](comparativa-original-vs-maquina.es.md)
- [Transcripción semántica completa en Markdown](BBPDC_BBPPC_Recipe_en.md)
- [PDF original público](https://cdn.shopify.com/s/files/1/0348/3467/7900/files/BBPDC_BBPPC_Recipe_en.pdf?v=1781305903) — la copia local se conserva en `output/pdf/`, una ruta ignorada por la política del repositorio
- [Manifiesto de procedencia y cobertura](manifest.json)
- [Facsímiles de las páginas](assets/pages/)

La guía convierte el mapeo en un método general: capacidad, porcentajes de panadero, hidratación, fermentación, selección de curso, inclusiones, formado y diagnóstico. La transcripción conserva las 50 recetas impresas. La comparación aporta los casos de evidencia: 37 panes y 6 productos relacionados de masa o panificación.
